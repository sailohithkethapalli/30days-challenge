Start the program.
Create a 2D array to represent the seats. Set every seat to available.
Show a menu:- Book a seat
- Cancel a booking
- Find consecutive seats for a group
- Show the occupancy report
- Exit

For booking or cancelling, ask for a row and seat number. Check that they are within range.
For a group, ask how many consecutive seats are needed, then search each row for that many available seats.
For the report, count booked and available seats and display them.
Repeat the menu until the user chooses Exit.
Stop.
